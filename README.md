# Dạy tớ đi

Game web: bé từ 4 tuổi dạy robot thỏ Mimi tiếng Anh. Điều Mimi học được làm thay đổi trò chơi.
Chạy hoàn toàn trên máy, không tài khoản, không ghi âm, không gửi dữ liệu đi.

## Chạy game

```bash
npm install
npm run dev        # mở địa chỉ Vite in ra, chơi ở màn ngang
npm test           # test đơn vị (Vitest)
npm run e2e        # test trình duyệt (Playwright); đặt PLAYWRIGHT_BROWSERS_PATH=D:/DevTools/playwright
npm run build      # tạo dist/ để phát hành
```

Công cụ: Phaser 4, TypeScript, Vite.
